# Study Rush 📚⚡

Study Rush is a learning app designed to help students understand school subjects, complete homework, create notes, and practise what they learn.

## Features

- Homework Helper
- AI-powered explanations
- Notes
- Practice Arena
- Quiz Generator
- Progress tracking and study streaks
- Support for multiple school subjects, including Mathematics, Further Mathematics, Physics, Chemistry, Biology, and English

## Project Structure

- `Study_Rush_V12.html` — the frontend of the application.
- `server.mjs` — the backend server.
- `package.json` — backend dependencies and project configuration.
- `Dockerfile` — configuration for deploying the backend.

## Deployment

The frontend can be hosted using GitHub Pages. The backend can be deployed separately using Render.

Configure the backend environment variable `OPENAI_API_KEY` in the Render dashboard. Keep your API key private. Never put it in this README, the frontend code, or a public GitHub repository.

## Important

The AI features require a correctly deployed backend and a valid API key. Make sure the frontend is configured to connect to your deployed backend.

## Purpose

Study Rush aims to make learning more interactive, accessible, and enjoyable for students.
